# 데이터거버넌스팀 공개 홈페이지

무료 GitHub Pages로 운영하는 초기 PoC 홈페이지입니다. 외부 공개용 콘텐츠만 이 저장소에 보관합니다.

## 파일과 게시

- `index.html`: 소개·주요 활동·지식 공유 안내를 포함한 반응형 정적 홈페이지입니다.
- `.nojekyll`: 별도 Jekyll 처리 없이 정적 파일을 게시합니다.
- 게시 소스: `main` 브랜치의 루트(`/`). 별도 빌드 의존성이나 API 키가 필요 없습니다.
- 콘텐츠 변경은 PR로 제안하고 표시·링크·공개 범위를 검토한 뒤 병합하는 방식으로 운영합니다.

## 공개 범위

저장소 파일과 Git 이력도 공개됩니다. 내부 문서·개인정보·비밀번호·API 키·미승인 자료는 등록하지 않습니다. 내부 자료는 별도 비공개 저장소에서 관리합니다. LLM 호출과 OpenRouter 연결은 이 홈페이지에 포함하지 않습니다.

현재 예제 소개와 게시 예정 주제를 담은 첫 버전이며, 자료·연락처·브랜드는 추후 확정 후 추가합니다.
